# Yasir Portfolio

React + Vite portfolio project built from the provided portfolio JSX file.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```

## Project structure

- `src/`
  - `main.jsx`
  - `App.jsx`
  - `Portfolio.jsx`
  - `components/`
  - `hooks/`
  - `data/`
